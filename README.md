## Deploy (GitHub Pages)

Repository: `mustafa101iq/mustafa101iq.github.io`

1. Push to the `main` branch.
2. Repo → **Settings** → **Pages** → Source: **GitHub Actions**.
3. The workflow `.github/workflows/deploy.yml` builds and publishes automatically.
