# Mustafa Q. Yassin — Portfolio

Personal portfolio website for **Mustafa Q. Yassin**, a Flutter mobile application developer based in Diyala, Iraq.

**Live site:** [https://mustafa101iq.github.io](https://mustafa101iq.github.io)

---

## Overview

A bilingual (Arabic / English) portfolio built with **Flutter Web**, showcasing production mobile apps, professional experience, skills, and contact channels. Designed as a fast, responsive single-page experience with a dark visual identity and smooth scroll animations.

## Highlights

- Bilingual UI with full RTL support for Arabic
- Featured production projects (Shaghilni Iraq, Alwessam Express)
- Experience timeline, education, and technical strengths
- Responsive layout for mobile, tablet, and desktop
- Direct links to Google Play, App Store, and social profiles

## Tech Stack

| Layer | Tools |
| --- | --- |
| Framework | Flutter Web |
| State management | GetX |
| Responsive UI | ScreenUtil |
| Typography | Google Fonts (Orbitron, Rajdhani, Tajawal) |
| Persistence | GetStorage |
| Deploy | GitHub Actions → GitHub Pages |
